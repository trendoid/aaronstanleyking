# Go to a GiveCamp, get a cool sticker

![Laptop covered in conference stickers](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEh2zFUIkgf-VecvEt2SgmUmye0Bh0f_tV-a50KOZUNXeW78vjHRYDqbNTyl5_fuanvjUEC0hRkFflBmAYKOxPNLhXSNPiAAsxmFS0xSY6wQ2vWcqZfjcU_mSbCAd5ObMbgHA_5Nj2Flu3c/s1600-h/ltstickers%5B19%5D.jpg)

I'm posting this picture of my old laptop. It was my wife's first but then she wanted a netbook. So I was handed down this 32bit Toshiba. It is actually pretty good hardware. Both Windows 7 and Linux installed with ease. I use it for demo and cross platform game programming. Since I use it in demos I started with the stickers. I acquired several from all the conferences I attend and speak at.

It is now full. It is also now too slow for my everyday work. It gets too hot and the battery doesn't last very long. I am very proud of one sticker though. I got it from [Dreams for Kids](http://dreamsforkids.org/) for writing code at the [Midwest GiveCamp](http://midwestgivecamp.org/).

![Dreams for Kids GiveCamp sticker close-up](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgBbA6ItYJil0Lyilebf_WIgsxB183uGrsPODpJ1QAPS5C7o7mepO91GOoz1-Yv_EcTCxb07iqKQxEu2Jk7Eod3JRrT1sEo_FlbD2-P6Oof-4KeCMD2eOJrenn6zbEo3N2zQ-b1aG21WTs/?imgmax=800)

If you haven't attended a GiveCamp, the [Indy GiveCamp](http://indygivecamp.org/) is Nov 5th. Be there or be square.
