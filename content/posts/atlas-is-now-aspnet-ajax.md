# ATLAS is now ASP.NET AJAX

![ASP.NET AJAX development](https://images.unsplash.com/photo-1516321318423-f06f85e504b3?ixlib=rb-4.0.3&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D&auto=format&fit=crop&w=2070&q=80)

As development of the AJAX-based extensions to ASP.NET nears final release, the code-name of "Atlas" has been replaced with the official product name of ASP.NET AJAX.

http://www.asp.net/

I hated that Microsoft renamed Ajax to Atlas. I love that they renamed Atlas to Ajax.

---

*Historical Context: This post captures a significant moment in web development history. Microsoft's Atlas framework was their answer to the growing AJAX revolution that was transforming web applications. The rename from Atlas back to ASP.NET AJAX reflected Microsoft's commitment to embracing web standards and the broader AJAX movement that was making web applications more interactive and responsive. This technology would become foundational to modern ASP.NET development.*
