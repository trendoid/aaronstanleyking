# My Experience as a Tech Reviewer

![Technical writing and book review process](https://images.unsplash.com/photo-1481627834876-b7833e8f5570?ixlib=rb-4.0.3&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D&auto=format&fit=crop&w=2128&q=80)

I recently got the chance to be a tech reviewer on [Pro C# 9 with .NET 5](https://www.amazon.com/Pro-NET-Language-Platform-Features/dp/1484269381) by Phil Japikse and Andrew Troelsen. It is a particularly informative book and goes through all aspects of C# 9. If you were going to get one C#9 book, you should get that book. I got to see what goes into a book like this and I can tell you that it is well worth the price.

Publishing a technical book is a lot of work. The authors need to know the subject matter inside and out. Writers know the subject matter so well that they can write about it in a way that is both educational and keeps the reader's attention. Editors must make sure there are absolutely no mistakes. Publishers must make sure everything is on time and on budget to make the book a success.

Then there are the tech reviewers. My job was to go through chapters line by line and test it. I looked for technical typos and logic errors. I also tested the code that was in the written examples by putting that code in Visual Studio and making sure it compiled and worked as described.

## What I Learned

The process taught me a lot about:

- **Attention to Detail**: Every code sample needs to be perfect
- **Communication**: Providing clear, constructive feedback to authors
- **Technical Accuracy**: Ensuring examples work across different environments
- **The Publishing Process**: Understanding how technical books come together

It was rewarding to contribute to a resource that will help thousands of developers learn C# 9 and .NET 5. The experience has given me a new appreciation for technical authors and the entire publishing ecosystem.

If you get the opportunity to be a technical reviewer, I highly recommend it. It's a great way to give back to the community while deepening your own understanding of the technology.
