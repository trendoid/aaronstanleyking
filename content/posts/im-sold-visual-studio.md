# I'm Sold!

![Visual Studio IDE development environment](https://images.unsplash.com/photo-1555066931-4365d14bab8c?ixlib=rb-4.0.3&ixid=M3wxMjA3fDB8MHxwaG90by1wYWdlfHx8fGVufDB8fHx8fA%3D%3D&auto=format&fit=crop&w=2070&q=80)

Ok Microsoft. You got me. I'm sold. How did you know that is exactly what I would have wanted from the start. The new default environment settings are awesome.

> **Based on "Web Development" settings but additionally optimizes for maximum text editor space by hiding tool windows, tool bars, and non-essential UI. Design View, validation, and non-essential background processes are also disabled.**

This is exactly what developers have been asking for - maximum code space with minimal distractions. Finally, a Visual Studio configuration that understands that sometimes we just want to write code without all the extra chrome getting in the way.

The focus on text editor real estate makes such a difference in daily productivity. When you're deep in code, every pixel of screen space matters for seeing more of your logic at once.
